# Palettes

Fixed palettes for the quantise effect, one `.hex` file per palette: one RRGGBB colour per line, no `#` and no comments (the format Lospec exports).

To add a palette, download the `.hex` from its page on https://lospec.com/palette-list and drop it in here. The filename corresponds to the palette's name, and can be used in the command after `--palette`.

| File | Colours | Source |
|---|---|---|
| `1bit.hex` | 2 | Black and white |
| `gameboy.hex` | 4 | Original Game Boy (DMG) greens, dark to light |
| `cga.hex` | 4 | CGA mode 4, palette 1 high intensity (black, cyan, magenta, white) |
| `cga16.hex` | 16 | Full CGA / EGA default 16 colours |
| `zx-spectrum.hex` | 15 | ZX Spectrum, normal then bright |
| `commodore64.hex` | 16 | Commodore 64, as on Lospec |
| `pico-8.hex` | 16 | PICO-8 fantasy console |
| `dawnbringer-16.hex` | 16 | DawnBringer's DB16 |
| `sweetie-16.hex` | 16 | Sweetie 16 by GrafxKid |
